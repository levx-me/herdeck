# 키와 마우스

[English](keys.md) · **한국어** · [← README](../README.ko.md)

## 열기, 닫기, 옮기기

herdr가 알아보는 에이전트(Claude Code, Codex, OpenCode 등)가 시작되면 그 옆에 deck이 저절로 열립니다.
그 밖의 경우를 위해 herdr의 `config.toml`에 키를 추가하세요.

```toml
[[keys.command]]
key = "prefix+d"
type = "plugin_action"
command = "steading.toggle"
```

- `prefix+d`는 포커스된 패널 옆에 deck을 열거나 닫습니다. deck 위에서 누르면 그 deck을 닫습니다.
- deck은 에이전트 오른쪽에 열리고, 에이전트 패널이 옆에 두기엔 좁으면(140칸 미만) 위에 열립니다.
  deck에서 `L`을 누르면 반대쪽으로 옮겨지고, 그 에이전트의 deck은 계속 그쪽에 열립니다.
- 닫은 deck은 닫힌 채로 있습니다. 실행 기록은 계속 쌓이고, 다시 열면 보입니다.
- 에이전트가 시작될 때도 열리지 않게 하려면: `touch ~/.config/herdr/plugins/config/steading/no-auto-open`.

## 키

deck에 포커스를 두세요(클릭하거나 herdr의 패널 이동 키 사용). 맨 아래 줄에 지금 쓸 수 있는 키가 항상
표시됩니다.

| 위치 | 키 | 동작 |
|---|---|---|
| 어디서나 | `[` `]`(또는 `tab` `shift+tab`), `1`–`7` | 이전/다음 탭, 해당 탭으로 이동 |
| | `L` | deck을 에이전트의 반대쪽으로 옮기기 |
| | `q` | deck 닫기 |
| 실행 목록 | `j` `k`(또는 `↓` `↑`), `gg` `G` | 실행 고르기(최신이 위) |
| | `enter` `l` | 출력으로 들어가기 |
| 출력 | `h` `j` `k` `l`, `w` `b` `e`, `W` `B` `E`, `0` `^` `$`, `{` `}` | 커서 이동(herdr 복사 모드 키) |
| | `gg` `G`, `ctrl+d` `ctrl+u` | 맨 위/맨 아래(`G`는 실행 중인 출력을 다시 따라감), 반 페이지 |
| | `v` `V`, `y` | 글자/줄 단위 선택, 복사(선택이 없으면 커서 줄) |
| | `/` `?`, `n` `N` | 앞/뒤로 검색, 반복 |
| | `esc` | 선택 취소, 또는 실행 목록으로 돌아가기 |
| servers | `o` | 브라우저에서 서버 열기 |

방향키는 어디서나 `h` `j` `k` `l`과 같습니다. 커서가 목록에 있으면 실행의 명령과 로그가 흐리게 보이고,
로그로 들어가면 반대가 됩니다.

## 마우스

- 탭, 실행 목록의 항목, 로그 줄, 서버를 클릭합니다.
- 휠은 로그를 스크롤하고, 실행 목록 위에서는 실행을 차례로 고릅니다.
- 로그를 드래그하면 herdr처럼 선택한 부분이 복사되고, 선택 영역 위에 알림이 뜹니다.

복사는 `pbcopy`, `wl-copy`, `xclip` 순으로 쓰고, 없으면 터미널 클립보드(OSC 52)를 씁니다.
